# Camera Grip Voronoi

Parametric and computational design workspace for developing a custom
camera-controller grip with a surface-aware Voronoi/cellular structure.

This repository is the **canonical home of the project**.

Earlier development was spread across multiple experimental repositories.

Those repositories have been consolidated here rather than deleted so that
their source code, generated models, configuration, and design decisions
remain available for reference.
