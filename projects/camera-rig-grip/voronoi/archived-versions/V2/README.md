# Camera Right Grip — V2 Corrected Boolean

This rebuild starts from the last known-good canonical 98 mm grip models and fixes the V2 Voronoi cutter coordinate error before subtraction.

## Critical correction

The previous `Voronoi_Cutters_V2.stl` had the intended side-profile axes emitted as `(X, Z, Y)` instead of canonical grip coordinates `(X, Y, Z)`.

The corrected cutter is therefore transformed by swapping Y and Z, producing canonical bounds:

- X: -30 .. +30 mm
- Y: -36.5456 .. +27.5374 mm
- Z: +10.8026 .. +72.0873 mm

The final grip is generated by an **exact OpenSCAD/CGAL Boolean**:

`Camera_Right_Grip_HOLLOW_V2_98mm - Voronoi_Cutters_V2_ALIGNED`

No voxel approximation is used for this final corrected Boolean.
