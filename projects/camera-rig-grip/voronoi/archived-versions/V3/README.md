# Camera Right Grip — Voronoi V3

V3 replaces planar-prism cutters with a surface-band cellular strategy.

## Main asset
`assets/Camera_Right_Grip_V3_CELLULAR_98mm.stl`

## Process
- Canonical 98 mm master remains unchanged.
- Voxel resolution: 0.80 mm.
- 15 seeds are sampled on the actual exterior surface.
- A 3D Voronoi field is built in a 5.6 mm exterior structural band.
- Cell boundaries are thickened into ~5.2 mm structural ribs.
- A protected electronics liner, solid heel, solid top, upper transition, and rear structural spine are unioned into the design.
- The placeholder electronics cavity is removed.
- Connectivity and manifold state are validated.

## Notes
This is a topology prototype, not the final electronics-fit revision. V4 should use the actual Lolin S2 Mini, joystick, button boards, battery, connector and wiring envelopes.
